📄 Module 1: Basic HTML Structure & Formatting
1. HTML Page Structure Basic HTML
प्रत्येक वेबपेजची मूलभूत रचना बनवण्यासाठी:
<html> <head> <title>Page Title</title> </head> <body bgcolor="plum"> ... Content ... </body> </html>
💡 मराठीत: <head> मध्ये टायटल व लिंक्स असतात, तर <body> मध्ये स्क्रीनवर दिसणारा सर्व कंटेंट असतो.
2. Text Formatting Tags Formatting
अक्षरांचा आकार व डिझाइन बदलण्यासाठी:
<h1> to <h6> ➔ Headings <b> ➔ Bold <i> ➔ Italic <u> ➔ Underline <font color="red" size="4"> ➔ Font Styling <br> ➔ Line Break | <hr> ➔ Line
💡 मराठीत: <b> ने मजकूर जाड होतो, <i> ने तिरपा होतो आणि <u> ने खाली रेघ येते.
📋 Module 2: HTML Lists (Ordered & Unordered)
1. Lists & Centered Symbols Lists
क्रमान्वये किंवा बुलेट्सने याद्या बनवण्यासाठी:
<ul type="square"> <li>HTML5</li> </ul> <ol type="A"> <li>Physics</li> </ol>
💡 Pro Tip: लिस्टचे नंबर्स किंवा बुलेट्स सेंटरला आणण्यासाठी CSS मध्ये list-style-position: inside; वापरा!
📌 List Types Summary:
• Unordered (`<ul>`) Types: disc, circle, square, none
• Ordered (`<ol>`) Types: 1, A, a, I, i
📝 Module 3: HTML Forms & Validations
1. Form Controls & Validation Forms
युझरकडून डेटा इनपुट घेण्यासाठी:
<form action="login.java"> Text: <input type="text" name="user" required> Pass: <input type="password" name="pass"> Mobile: <input type="text" pattern="[0-9]{10}"> Radio: <input type="radio" name="g" value="m"> Check: <input type="checkbox" name="c"> Select: <select><option>Pune</option></select> <input type="submit" value="Submit"> </form>
💡 मराठीत: pattern="[0-9]{10}" द्वारे मोबाईल नंबर नक्की १० अंकीच असल्याचे व्हॅलिडेट केले जाते. radio मध्ये एकच पर्याय निवडता येतो.
📌 Radio vs Checkbox Note:
• Radio (`type="radio"`): एकाच `name` मधील फक्त १ पर्याय निवडता येतो (उदा. Male/Female).
• Checkbox (`type="checkbox"`): एकापेक्षा जास्त पर्याय एकत्र निवडता येतात (उदा. Courses / Pass).
📊 Module 4: HTML Tables & Cell Merging
1. Table Layouts & Spans Tables
डेटा रो व कॉलमच्या स्वरूपात मांडण्यासाठी:
<table border="2" cellpadding="8"> <tr> <th>Roll No</th> <th>Name</th> </tr> <tr> <td>1</td> <td>aaaa</td> </tr> <tr> <td colspan="2" align="center">Total: 1</td> </tr> </table>
💡 मराठीत: colspan="2" ने कॉलम जोडले जातात, rowspan="2" ने रो जोडल्या जातात आणि cellpadding ने सेलच्या आत जागा मिळते.
🖼️ Module 5: Images, Links & IFrames
1. Media & Page Connecting Links & Iframes
फोटो दाखवणे व पेजेस कनेक्ट करणे:
<!-- Image Tag --> <img src="car1.jpeg" width="200" height="150"> <!-- External Link --> <a href="https://google.com" target="_blank">Google</a> <!-- Mailto Link --> <a href="mailto:contact@car.com">Email Us</a> <!-- Iframe Target Connecting --> <a href="welcome.html" target="contentFrame">Open</a> <iframe name="contentFrame" src="welcome.html" width="100%" height="300"></iframe>
💡 मराठीत: target="contentFrame" मुळे क्लिक केलेली फाईल थेट दिलेल्या <iframe> मध्ये ओपन होते.
🎨 Module 6 & 7: CSS Types, Box Model & DIV Layouts
1. CSS & Box Model Layouts CSS & Divs
पेजचे लेआउट व रंग ठरवण्यासाठी:
/* External CSS Link */ <link rel="stylesheet" href="carweb.css"> /* CSS Properties */ body { background-image: url('wcake1.jpeg'); background-size: cover; } .header { width: 100%; height: 10%; background: yellow; } .list { width: 20%; float: left; background: pink; } .content { width: 80%; float: right; background: gray; overflow-y: auto; } .footer { width: 100%; clear: both; background: yellow; } .limenu { display: inline; padding: 10px; }
💡 मराठीत: float: left व float: right ने डावा-उजवा लेआउट बनतो, clear: both ने फुटर खाली येतो आणि display: inline ने मेनू आडवा होतो.
